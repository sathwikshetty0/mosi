# MOSI | Interview Intelligence Engine

**Elite discovery framework for strategic stakeholder synthesis.**

![Premium Interface Preview](https://img.shields.io/badge/UI-Elite--High--Contrast-blue?style=for-the-badge)
![Tech Stack](https://img.shields.io/badge/Tech-Next.js%20%7C%20Zustand%20%7C%20Tailwind-black?style=for-the-badge)

MOSI (Meeting Opportunity & Strategic Insight) is a high-performance web application designed to transform raw stakeholder conversations into structured, actionable strategic artifacts. Built on the proprietary **CEED Framework**, MOSI enables interviewers to capture, synthesize, and publish professional-grade intelligence archives with absolute precision.

---

## 🧭 The CEED Methodology

MOSI is built around four critical discovery quadrants:

*   **CORE**: Foundation, product status, and immediate challenges.
*   **EFFICIENCY**: Operational bottlenecks and resource optimization.
*   **EXPANSION**: Market adjacent opportunities and growth vectors.
*   **DISRUPT**: High-stakes innovation and industry-shifting threats.

---

## ⚡ Key Features

### 1. Live Discovery Engine
A real-time interview interface featuring:
*   **Command Active Status**: Visual recording indicators and temporal tracking.
*   **Active Question Stream**: Framework-guided prompts tailored to the CEED quadrants.
*   **Synthesis Action Pad**: One-tap logging for strategic insights and evidence (Images, Docs, Links, Video).
*   **Chronology Footer**: A professional timeline visualizing the flow of discovery.

### 2. Validation & Synthesis Workspace
The bridge between raw data and executive reporting:
*   **Synthetic Summary**: A dedicated environment for interviewers to synthesize high-level overviews while reviewing audio artifacts.
*   **Insight Register**: A granular tuning environment to refine and score captured opportunities.
*   **Interactive Transcript**: Auto-generated session records for deep forensic analysis.

### 3. Executive Preview Hub
High-impact reporting for stakeholders:
*   **Item-Level Verification**: Secure review portals where stakeholders can approve, hide, or comment on specific findings.
*   **Professional PRD Generation**: Automated drafting of technical requirements from the discovery feed.
*   **Branded Documentation**: Consistent, high-contrast industrial aesthetics.

### 4. Global Intelligence Dashboard
A central command center for the entire discovery cycle:
*   **Elite Analytics**: Global tracking of insights, stakeholder expansion, and pipeline health.
*   **Active Archives**: A secure repository of all past stakeholder engagements.

## 🛠 Tech Stack

*   **Framework**: [Next.js 15](https://nextjs.org/) (App Router)
*   **State Management**: [Zustand](https://github.com/pmndrs/zustand) (Persistent Local Engine)
*   **Aesthetics**: Vanilla CSS + Tailwind Utility Overlays
*   **Icons**: [Lucide React](https://lucide.dev/)
*   **Recording**: MediaStream & MediaRecorder API

## 🚀 Getting Started

### Prerequisites
*   Node.js 18+
*   NPM or Yarn

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/sathwikshetty0/mosi.git
   cd mosi
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Launch the Development Server:
   ```bash
   npm run dev
   ```

4. Open [http://localhost:3000](http://localhost:3000) to initiate your first discovery session.

---

## 🛡 Security & Privacy
MOSI utilizes a **Local Buffer Secure** architecture. All discovery metadata is processed and stored within local state buffers, ensuring that sensitive stakeholder dialogues remain encrypted and protected throughout the synthesis cycle.
