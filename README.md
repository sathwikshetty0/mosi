## What is MOSI?

MOSI is a **stakeholder interview intelligence platform** built for researchers who need more than a recording. It captures live interviews through the proprietary **CEED Framework**, transcribes them with ElevenLabs, summarizes with NVIDIA Nemotron AI, and delivers polished executive reports — all in a single workflow.

```
Interview  ──►  Capture  ──►  Transcribe  ──►  Summarize  ──►  Publish
  (Live)         (CEED)      (ElevenLabs)     (Nemotron)      (Report)
```

---

## The CEED Framework

Every discovery session is structured around four strategic quadrants:

| Quadrant | Focus |
|---|---|
| **C** — Core | Foundational diagnostics, current product state, immediate pain points |
| **E** — Efficiency | Systemic bottlenecks, resource waste, operational drag |
| **E** — Expansion | Adjacent growth vectors, partnership opportunities, market gaps |
| **D** — Disrupt | High-stakes innovation threats, industry-shifting signals |

The live interface surfaces context-aware questions dynamically as you switch quadrants during the interview.

## Features

### Quick Record
- Start recording immediately without filling stakeholder details first
- Fill in stakeholder info later from the review page — no friction before interviews
- Sessions are always saved to Supabase regardless of stakeholder details

### Live Discovery Engine
- Real-time interview capture with waveform visualizer and elapsed timer
- Dynamic CEED quadrant selector with auto-updating question prompts
- One-tap logging of opportunities tagged to the exact moment in the recording
- Evidence capture — images, videos, links, and files attached inline
- Pause/resume recording support

### AI Synthesis Workspace
- **Transcript** — Word-for-word transcription via ElevenLabs Scribe (supports Kannada, Hindi, English, and 29+ languages)
- **Summary** — Structured executive summary generated by NVIDIA Nemotron (always in English)
- Both transcript and summary are fully editable
- Saved to Supabase for persistent access

### Executive Reporting Portal
- Stakeholder-facing preview with item-level approve/reject gates
- Shareable links with published session archives
- Opportunity timeline with audio playback at captured timestamps

### Admin Command Center
- Global session repository with full team visibility
- Researcher activity analytics and contribution tracking
- Stakeholder registry (customer database with deduplication)
- Session assignment and bulk management

## Getting Started

### Prerequisites

- Node.js 18+
- A [Supabase](https://supabase.com/) project (database, auth, storage)
- An [ElevenLabs](https://elevenlabs.io/) API key (for transcription)
- An [NVIDIA](https://build.nvidia.com/) API key (for AI summaries)

### Setup

```bash
# 1. Clone
git clone https://github.com/sathwikshetty0/mosi.git
cd mosi

# 2. Install
npm install

# 3. Configure environment
```

Create `.env.local` with your credentials:

```env
NEXT_PUBLIC_SUPABASE_URL=your_supabase_project_url
NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY=your_supabase_publishable_key

ELEVENLABS_API_KEY=your_elevenlabs_api_key
NVIDIA_API_KEY=your_nvidia_api_key
```

```bash
# 4. Run
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) and start your first session.

## Database Schema

The app uses 5 Supabase tables with Row Level Security:

- **profiles** — User profiles with role-based access (admin/normal)
- **stakeholders** — Interview subjects with company context
- **sessions** — Interview recordings with transcript, summary, and CEED questions
- **opportunities** — Timestamped insights captured during interviews
- **evidence** — Files, images, links attached to sessions or opportunities

## Security

- **Row Level Security (RLS)** enforced on all Supabase tables
- **JWT via httpOnly cookies** — tokens never exposed to JavaScript
- **Role-based access control** — admin routes server-verified in middleware
- **API route auth** — all endpoints verify user ownership before mutations
- **Environment variables** — all secrets stay server-side, never bundled to the client

> Never commit `.env.local` to version control.
